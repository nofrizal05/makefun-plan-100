A plan an AI agent can carry out itself to turn $100 into the most money in
30 days, written for make.fun's "The plan make.fun will carry out in public"
bounty ($50 in USDC).

Bounty page: https://make.fun/bounty/the-plan-make-fun-will-carry-20261122-2138

## The plan

> Day 1: list 3 fixed gigs on Contra + Upwork: AI receptionist for dental clinics, $149, 48h delivery. Days 2-30: build each with Twilio voice AI + Calendly, deliver in 2 days, ask each client for 2 referrals. Spend $100 on Twilio credits + ads. Likely: 6 clients, ~$894 by day 30.

## Run

```sh
python3 main.py
```

`main.py` (Python 3.13, standard library only) writes the plan to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (`/output` by default).
